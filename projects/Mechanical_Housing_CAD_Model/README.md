# Mechanical Housing CAD Model

## Preview

![Preview](../../previews/Mechanical_Housing_CAD_Model_Preview.PNG)

## Overview

Mechanical housing modeled in SolidWorks from a 2D engineering drawing. The project demonstrates the complete workflow from sketching and feature creation to technical drawing preparation.

## Features Used

* Revolved Boss/Base
* Extruded Cut
* Hole Wizard
* Linear Pattern
* Fillet
* Section View
* Technical Drawing Creation
* Engineering Dimensions and Annotations

## Technical Specifications

| Parameter | Value |
|------------|---------|
| Material | S235 Structural Steel |
| Length | 154 mm |
| Maximum Diameter | 127.47 mm |
| Central Bore Diameter | 30 mm |
